CS 释义：历史上第一个被记录的计算机 Bug。1947 年 9 月 9 日，Harvard Mark II 继电器里夹着一只死掉的飞蛾，Grace Hopper 把它取出、用胶带贴进工作日志，旁边写 "First actual case of bug being found"。
但这一集的飞蛾不是真正的飞蛾，是一个工程师七个月前在一份 PR description 里写下的一行字，那行字后来卡在公司机器的齿轮里没人发现，直到它咬伤一个二十四岁的女孩。
 
【第一场 / Noesis 自建数据中心 / 凌晨三点 / 蓝白色机房光】
机柜一排排延伸到黑暗里。冷通道顶灯亮着，风扇声像一场压低的雨。Ravi 坐在临时折叠桌前，面前四块显示器。左边是 GPU cluster utilization，右边是训练 loss 曲线，中间是 Slack，最下面一块屏幕滚着日志。他戴着一只耳机，另一只耳朵露在外面。眼下发青，胡茬没刮干净。桌上有三罐空能量饮料，一盒没拆封的寿司已经发干。

屏幕上：
Epoch 18 / 42
Loss: 2.4173
GPU Temp: Nominal
CPU Temp: Nominal
Network: Nominal
 
旁边的年轻工程师 Jason 躺在两把椅子拼出来的临时床上，帽衫盖住脸。
Ravi 摘下耳机。
Jason：“又怎么了？”
Ravi 没看他。他侧耳听着机柜深处的风扇声。“它每次死之前，风扇声音都会变细。”
Jason 把帽衫往下拉一点。“你连续二十七小时没睡，听什么都细。”
Ravi 手指悬在键盘上，没按。“不是所有风扇。只有B05 那一排。”
Jason说，“B05 整机换过两次。”
Ravi 起身，走到冷通道门口。玻璃门里，机柜指示灯密密麻麻闪着绿光。全绿。
Slack 开始跳。
`train-prod-17 loss spike`
`nan detected`
`nan detected`
`nan detected`
中间屏幕上，loss 曲线平稳地走了半秒，然后像被刀切断一样垂直炸开。
红色弹窗占满屏幕。NaN LOSS DETECTED. JOB TERMINATED.
Jason 坐起来。“操。”
 
Ravi 没骂。他站在玻璃门前，盯着 B05。他从口袋里摸出手机，打开录音，贴近玻璃门。风扇声很密，在密声底下，有一条极细的高频啸叫。
 
【第二场 / 霍珀的公寓 / 周日下午 / 客厅】
霍珀盘腿坐在地毯上，笔记本放在膝盖上。窗外高速的车声低低铺着。屏幕上是 Noesis 的 runbook。几十页，表格、曲线、故障时间线。手机开着免提，克努斯的声音从里面出来。
“老张说他们什么都试过了。PyTorch、CUDA、driver、交换机、softmax clipping。现在他们都开始怀疑自己大楼风水不好了。”
霍珀快速翻着runbook，“他们给不给物理访问？”
“给。你要 screwdriver 他们都给。”
“谁说风水？”
“老张。”
“告诉老张，风水不背锅。我周二上午过去。”
“你又准备让一个 CTO 难堪？”
霍珀把 runbook 停在 B05 机柜的故障频率统计表上。
“我还没见到他。“
她挂断电话。屏幕光照在她脸上。她把 B05 圈出来。
 
【第三场 / Noesis 数据中心 / 周二上午 / 机房入口】
Ravi 站在门禁旁，胸前挂着 visitor escort badge。他看见霍珀从走廊尽头走来，黑色公文包，深灰西装外套，黑色短靴，短发梳得整齐。Ravi 下意识站直。“Hopper？”
霍珀说，”Ravi？”
“你怎么知道？”
“runbook 里只有一个人半夜三点还在更新注释。语法很烦人。”
Ravi 愣了一下，低头刷门禁。机房门打开，冷气扑出来。“你要先看 dashboard 还是 logs？”
“你说风扇声变细了。”Ravi 停住。霍珀接着问，“哪一台？”
Ravi 看着她没动，像没听清。“你看了我的那条记录？”
Ravi 从口袋里摸出手机，打开那段凌晨录音。风扇声从手机扬声器里冒出来，音频被压缩过，发脆。Ravi说，“B05-R12。每次出事前五分钟，那个高频声音会出来。Thermal telemetry 看不见，rack sensor 也看不见。”
旁边两个 Noesis 工程师交换眼神。工程师 A说，“我们整机换过。主板、SSD、CPU 都换过。OS 也重装过。“
霍珀看向 B05，说，“侧盖打开。”
工程师 A：“现在？”
霍珀：“现在。”
 
服务器被拉出机柜。金属侧盖卸下来，放到地上。霍珀蹲下，打开手机手电。冷白光扫过散热片、线缆、风扇罩。Ravi 也蹲下来，手搭在膝盖上，屏住呼吸。
霍珀：“底板。”
工程师 B：“什么？”
霍珀已经从公文包侧袋拿出一支细长的检查灯。
Ravi 忍不住笑了一下，“你竟然随身带这个。”
霍珀：“你们怎么不带？”
 
工程师 B 拧开底板。金属板落到地上，露出服务器底部的风道。检查灯的光扫过线束、灰尘、扎带，光线被拦截在 CPU 1 下方的导流槽。
那里卡着一段黑色泡棉，手指长，边缘被热风吹得卷起来，一面还粘着半片已经失效的胶。
 
机房里安静了两秒。
工程师 A：“不可能。”
霍珀戴上手套，把那段泡棉慢慢取出来，放进透明自封袋。
Ravi 凑近看导流槽里留下的浅浅压痕，说“它不挡进风口。”
霍珀：“挡的是局部气流。全局温度不变，但局部温度梯度变。”
Ravi：“Telemetry 看不到。”
霍珀点头。
Ravi 转身抓起笔记本，飞快敲键盘。“Xeon errata。AVX-512。thermal gradient。”
霍珀：“搜 silent incorrect result。”
Ravi 敲下回车。屏幕上弹出 PDF。两人同时看见那条不起眼的 erratum。Ravi 把椅子往后一推，笑了一声，又马上停住，“八个月。”
霍珀说，“你昨晚已经听见了。” Ravi 没说话。他看着自封袋里的黑色泡棉。
 
【第五场 / 周一下午两点二十 / Aaron Park 的办公室】
Noesis 的 CTO Aaron的办公室在Noesis总部三楼最里面，有两面落地窗，一面对着停车场，一面对着后山。冬天的山是黄褐色的，光从云层后面渗下来，落在地毯上是一块灰白色的方形。
Aaron没绕到办公桌后头，他指了指窗边的小茶几，"过来这边坐。"
霍珀过去。她把外套挂在椅背上，公文包放在脚边，坐下的动作和她坐会议室那把椅子一模一样，利落，不挑地方。
茶几上摆着一个电热水壶，日本牌子，铜色把手；Aaron 拿起一个铁罐，从里头夹出茶叶，闻了一下，放进一个小白瓷壶。水沸腾了，Aaron 冲水进瓷壶。茶叶在水里翻了一圈。他没立刻倒。他在等。他做这件事的样子是做过五百次的样子——每天给客人泡茶，泡了十年。
 
"你这次的 fee 是 35K。三天。"
"嗯。"
他把茶汤倒进两个小杯子，先推一杯给她。茶汤是浅琥珀色的，热气从杯口直直地往上走。霍珀的手没动。
"我可以让财务今天给你转 70K。"
霍珀看他，但什么都没说。茶杯垫上有一圈极小的水痕。霍珀的左手食指无意识地碰了一下杯壁。很烫，她没缩。
Aaron 给自己也倒了一杯。他放下壶，说："我们下周一有 B 轮的 final 会议。Sequoia 已经签了 term sheet，Andreessen Horowitz 还在 DD，最后一轮。我们计划融 1.4 亿美金。"
"嗯。"
"这个 NaN 的 bug 他们在 DD 里问过两次。他们问 root cause。"
"嗯。"
"我们的 CTO report 上周已经写好了。我准备本周三签。报告里 root cause 写的是硅错误，NVIDIA 2023 年 3 月公布的 H100 erratum；我们的解决方案是 thermal headroom 增加，加上在 ML 层加一个 NaN filter，accept 大概 3% 的训练效率损失。"他停了一下。"这份报告会过 DD。Sequoia 已经看过初稿。他们说没问题。"
霍珀终于把茶端起来，她喝了一口，茶很好。"那块泡棉呢？"
Aaron 没立刻答。他低头看他自己的茶。"如果你的报告里写泡棉——"，他抬头，"Sequoia 的 DD team 会问，这块泡棉是谁装的。我们要回答，一年前的外包。他们会问，为什么没有 part number。我们要回答，我们当时没有那种流程。他们会问，你们现在有了吗。还没。然后他们会要求我们做一次完整的 facility audit。这次 audit 大概需要三到六个月。在 audit 完成之前，他们的 final commitment 不会下来。"
"我们的 runway 还有四个月。"
霍珀放下茶杯。
"如果 B 轮没有按时下，我们要裁员。"Aaron 说。"我已经算过，保 production team 的话，我要裁掉 R&D 的 60%。大概 80 个人。"他看向她。"其中 30 个是 H1B。"
霍珀的手在膝盖上。她的左手腕上那块表反着窗外的光，表盘是她父亲送她那年的那个样子，皮表带磨得发白。
 
"Hopper。"
"嗯。"
"我不是在让你撒谎。NVIDIA 的 erratum 是真的。我们的 H100 在那个温度区间会 bit flip 是真的。这个公司有 thermal design 的问题是真的，那块 泡棉 是 thermal design 失败的一部分。如果我把 root cause 写成 erratum 加 thermal design issue，每一句都是真话；唯一不写的是那块泡棉是怎么来的。"
Aaron 又给她杯里添了一点茶。茶水从壶嘴出来的时候他的手没抖。"你的发现没有被埋掉。Ravi 的发现也没有被埋掉。我们会修。我们已经从 B05 把 泡棉 拿出来了，正在做全机房的物理 audit，我们会在内部建一个流程；只是这份给 Sequoia 的报告，它的范围是 root cause，泡棉的 facility 故事不在那个范围里。"
 
霍珀看着 Aaron。她看了很久。
"Aaron。"
"嗯。"
"你说的每一句话都是对的。"
Aaron 没说话。他这种人精知道，当对方说"你说的每一句话都是对的"的时候，下一句不是"我同意"。
"但我不能写那份报告。"
Aaron 还是没说话。
"Sequoia 的 DD 是一次。"霍珀说，"如果下次有一块泡棉在某家公司的某个 rack 里，我不在那家公司，Ravi 不在那家公司，你不在那家公司；那家公司的 CTO 也会想，这次的 root cause 是什么对我最方便，他会想到硅错误、 thermal headroom、硅厂商的 erratum，他会想到这些是因为你写过的报告会被引用，这会成为 industry standard。然后下次的泡棉就一直在那里。"
Aaron 低头。他喝了一口茶。
他抬头，说，"你要我裁 80 个人。"
"我没让你裁任何人。"
"……"
"你的报告你写。我的报告我写。如果 Sequoia 看了我的报告决定不投，那是 Sequoia 的决定。你可以不附我的报告。你只交你的。"
"如果他们问 root cause，我不能交两份不同的版本。"
"那你交你的。我给你的报告你保留或者扔掉，我不在场。"

"Hopper。"
"Aaron。"她站起来。她拿西装外套搭在小臂上，俯身拎起公文包。"我把报告今晚发给你。我不收 70K。我也不收 35K。这次的 consult 不收费。"
她朝门口走去。
 
"Hopper。"
她回头。
"你为什么——"
她想了一下。她没立刻接。
"我十二年前在另一家公司投过一次反对票。我输了。后来发生了一些事，我活下来了，那家公司的几个用户没有。"
她看着 Aaron。
"这件事我每天都想。"
"那不是一个我能再做一次的事。"
 
黑屏。
片名出现。
UNDEFINED BEHAVIOR / 未定义行为
 Episode One: 机器飞蛾 / The Moth in the Machine
 
【第六场 / 周一下午三点四十 / 霍珀的公寓】
她到家是四点零三。一个安静的街区，一栋三层小楼的二楼，她有一间客厅、一间卧室、一间小书房；客厅的窗户朝东，正好看得到旁边的101公路。
客厅里很安静。冰箱在隔壁厨房响了一下又安静下来。窗外远处 101 的车流是一种持续的、低于人耳习惯的白噪声。
她站了大概十分钟后坐下，拿起笔记本电脑，打开 ping.hp 的后台。
她不应该今天打开，周日下午才看过，惯常每周看一次，今天她应该写 Aaron 的报告，她答应 Aaron 今晚发，还有大概五个小时。
但她还是打开了。
 
47 条新投稿。
她往下翻了几条后停住。
> UUID: 7af3-b211-09c4
> 我老板上周让我把一段代码 push 到 production。我看了那段代码。那段代码会在某些边界条件下删除用户的历史数据，没有 backup。
> 我跟他说了。我说这段不能上。他说没事，push。他说他来负责。
> 我 push 了。三天后，那段代码触发。一个用户的两年的数据被删除了。我们没有 backup，不能恢复。那个用户每天用我们的 app 来管理她的孩子的医疗记录。她的孩子有一个慢性病。两年的用药历史、过敏记录、和医生的沟通。全没了。
> 我老板今天告诉我他写了一份事故报告。报告里说是用户操作错误，用户自己删了数据。他让我签字确认，我下周一要去他办公室签。
> 我不知道该怎么办。
 
霍珀看完后想，这个人怎么找到 ping.hp 的。她发布这个网站三年了，她偶尔想这件事，她从来没问过任何投稿人怎么知道这个网站，她不想知道。但她偶尔想，比如现在，她会想。
 
她打开电脑，做了三件事。
她搜"医疗管理 app + 慢性病 + 数据丢失 + 用户投诉"，这种事故出现在哪个公司的范围。她得到一个 short list，三家湾区做小型医疗 app 的公司：Calix Health、Vyne Care、SimpleMed。她查了三家最近三个月的 Glassdoor 评论，Calix 的评论里有几条新的，匿名地抱怨"管理层 cover-up culture"，时间集中在最近一个月。她在 LinkedIn 上看 Calix 的工程师，大部分是 24 到 30 岁的年轻面孔，亚裔比例很高，新员工很多。她看了 CTO，Reza Akbari，40 岁，印度裔加拿大人，前 Google senior staff，Calix 的 co-founder 之一。
她看了 Reza 的 LinkedIn 三分钟。她不喜欢她看到的东西。不是那种她能说出来的不喜欢，是一种她做了二十年工程经理学到的本能——这个人不会让任何坏新闻出公司。
她从 LinkedIn 退出来后找到了她的前下属 Sarah Liu的联系方式，她在大厂当 manager 时带过的员工，现在自己做独立咨询。Sarah 的客户名单她不知道全部，但她记得一年前 Sarah 提过一个新客户，是一家做 health app 的小公司，她当时没记名字。
 
她给 Sarah 发信息：“你 Calix Health 的合同还在吗”
Sarah 五分钟后回：“在。怎么了“
”我能跟你谈半小时吗？“
”现在？现在十一点半“
”现在“

视频窗口打开。Sarah 出现在屏幕上。三十出头的女工程师，黑色细框眼镜，背景是她家的厨房，她刚做完饭，头发用一个小夹子夹在头顶。
"霍珀。"
"Sarah。我不告诉你为什么。"
"OK。"
"你给我讲 Calix Health 的内部。CTO Reza Akbari 是个什么样的人。最近有没有出过事故。内部文化怎么样。"
Sarah 看她两秒，说，"你确定不告诉我为什么？"
"确定。"
"Hopper。"
"嗯。"
"如果有一天我需要知道，你会告诉我？"
"会。"
Sarah 想了一下。"OK。"
 
她讲 Reza 是 Calix 的 co-founder 之一，一个聪明的、政治型的 CTO，他的招牌是"任何坏新闻不出公司"，任何 incident、任何用户投诉、任何 internal discontent，他都按内部解决，不让 PR 出去。她讲他有一个亲信，一个叫 Alex Rios 的 staff engineer，是 Reza 几年前从 Google 带过来的，Alex 是 Reza 的 hatchet man——脏活由 Alex 干。她讲两周前，Calix 确实出了一件事，一个用户发邮件投诉数据丢失，公司给了她一年免费服务作为补偿，要求她签 NDA。Sarah 说她当时听了内部说法是"用户操作错误"。
"我当时听了觉得不对劲。"Sarah 说。"一个普通用户怎么操作能让自己的两年数据全部消失。"
霍珀点头。她说，"Sarah。"
"我可能要做一件事。如果我做了，你不要参与。"
"霍珀，你别做傻事。"
"我尽量。"
Sarah 看着屏幕里的她，“你以前说“我尽量”的时候，通常已经在做了。”

"你最近——"，Sarah 停了一下，"——你最近怎么样。"
霍珀看她，"还好。"
她说，"我得睡了，Sarah。明天我可能再找你。"
"OK。"
 
视频窗口关上。她打开邮箱，写了一封邮件发到 ping.hp 投稿者用的那个一次性邮箱地址。
 
> 我愿意帮忙。我想我知道你在哪家公司工作。我就不点名了,你不必确认。
> 周一不要签任何东西。告诉你的老板你需要先咨询律师--你有这个权利，即使是 H1B。
> 如果你想谈谈，请回复这封邮件。如果你不回复，我会尊重你的意见。
> — H
 
【第七场 / 周二下午一点 / 霍珀的公寓】
Mei 回信了。
> 你是谁？
 
她回：
> 处理 ping.hp 消息的人。
> 我不是律师，但我有朋友是律师。如果你告诉我你不想签字，我可以帮你联系一个专门处理技术就业问题的人。
> 你的移民状态是什么？
 
二十分钟后 Mei 回：
> H1B还剩两年。我的绿卡申请由这家公司担保，EB-2 PERM，优先日期为 2023-03。如果我离开，就会失去优先日期，我已经等了快一年了。
> 公司知道这一点。

priority-1 ticket（Slack 自动广播，他会在 Slack 里看到）。
Sarah Liu 的周报问题（Sarah 一般周三中午发周报）。
她自己的邮件（直接进 Reza 的收件箱）。
三件事都问同一件事：第二阶段的verification。三件事的来源完全独立——一个是新 contractor 的内部 ticket，一个是另一个 contractor 的 routine 周报，一个是新 contractor 的 onboarding 邮件。Reza 没办法把它们联系 起来。他没办法说"她们串通"，因为如果他这样想，他必须解释为什么这三个独立的人在同一天问同一件事。
最简单的解释：第二阶段的verification 是一个真问题，外部专业的人都会问。
Reza 必须有所行动。
她想，他会叫 Alex 进办公室。他会要 Alex 给他一个解释。Alex 必须告诉他什么。Alex 可能主动背锅，或者他可能反咬 Reza——Reza 在 2023 年 6 月知不知道第二阶段推迟了？Reza 当时签了 PR description。他也在一条绳上。
但不管 Alex 和 Reza 在那个房间里怎么演，Mei 的"用户操作错误"故事已经站不住了。
因为如果 Calix 现在去重新 review 1 月 15 日的事故，他们会发现 backup 系统从 2023 年 6 月就没工作过。这不是 Mei 的过失。Mei 的代码是有 bug，但这个 bug 不是事故的根因。根因是 Alex 跳过了 verification。
Reza 4点时不能让 Mei 签"用户操作错误"，因为再过 24 小时，他自己内部的 SRE review 会发现 backup 问题，那时候 Mei 已经签的字会成为 Calix 在法律上故意误导的证据。也许 Reza 会推迟4点的会议。他会说"我们需要更多时间审核"。

下午一点半了，霍珀还要做第四件事——清场。
她写第二封邮件给 Reza。

> Reza,
>
> 接着我之前的说明，我就直说了，我在入职前审查中发现的数据完整性问题--尤其是第二阶段的验证漏洞比我预想的要严重得多。经过进一步思考，我认为这些问题需要你们现有的 SRE 领导层立即关注，而不是让外部 contractor 贸然介入。
> 我还担心，在正式入职之前，我在这个阶段的参与可能会给你们可能需要进行的任何内部审查带来麻烦。我不希望我的发现给内部责任问题蒙上阴影。
> 我想停止合同，不用支付我任何费用。我想你会希望由你的团队来处理这件事。
> 很抱歉通知时间太短。请告诉我，在我撤销自己的访问权限之前，是否需要提供任何交接文件。
>
> Best,
> Hopper

霍珀想，也许 Mei 4 点仍然要签什么。也许 Reza 推迟会议之后下周会想出一个新的故事来 cover。也许 Alex 反咬一口然后 Calix 内部内斗，Mei 仍然是处境危险的 24 岁 H1B。
但是，她想，我做了具体的事。我没让真相留在我手里。我把它推到了 Calix 内部，让那个机器自己处理。哦，我得去见爱达。
她忘了她要去见爱达。
她这两天没怎么睡，害怕如果这个时候去见咨询师，会在那里崩掉。
但她要去。她答应了克努斯。

【第十一场 / 周三下午三点五十三分 / Helion 员工健康中心二楼】
走廊尽头 207 号门。
霍珀站在门外。她穿着和周一同样的衣服，深灰色的羊毛西装外套搭在小臂上，白衬衫的袖口卷到小臂中间露出那块旧机械表，黑色直筒长裤，黑色真皮短靴，鞋底沾着一点 Noesis 停车场的水泥灰；她站在这扇门外的时候站得很直，肩膀打开，左手提着一个磨过几年的黑色皮质公文包。这是她进会议室的姿势，她进任何一个房间的姿势，是她在 Noesis 走进 CTO 办公室的姿势，也是她现在站在一个心理咨询师门外的姿势，她没有别的姿势可用。
她在门口停了三秒才敲门，均匀的三声。

室内。
林爱达坐在窗边那把扶手椅上，膝上摊开一份很薄的来访者档案，薄到几乎不存在。上面只有一页，写着姓名、年龄、推荐人 Dennis Knuth、初次访问理由"睡眠问题（推荐人转述）"。
林爱达今天穿一件淡黄色的针织衫，下面是一条深绿色的格纹裙；她的头发比平时还乱一些，因为早上下雨时她从停车场跑过来，到办公室时半边头发都湿了，她用毛巾胡乱抹了两下就忘了再梳；她涂了一支非常淡的玫瑰色口红，眼皮上没有眼影，早上没来得及，她答应自己中午补，然后忘了。
她膝上那份档案已经看了三遍，不需要再看了。
她把档案合上，抬头看了一眼窗外。下午的雨下得不大，落在窗外那棵不知道叫什么的小树上，叶子一颤一颤；她转回头看向门，因为她知道这一刻就要来了。她从早上九点开始就知道这一刻今天要来，从昨天晚上开始就知道，从上周克努斯把这个 referral 发给她的时候就知道。准确地说，她从二十一年前就在等这一刻，只是过去二十一年里她并不知道自己在等待。
她说，"请进。"

门开。霍珀走进来。
爱达抬头。她在抬头的那个瞬间——
镜头停在爱达的脸上。

她在那个瞬间脸上没有变化。她从小就学会了，想要一个东西时，不能显得想要。
但她的心里有一个东西在那个瞬间响了。不是震。是响。像一个钟在很远的地方响一下，余音留在胸腔里。
她看见霍珀走进来，四十一岁，瘦削得像一棵冬天的松，深灰西装、白衬衫、黑色短靴，左手腕上一块旧机械表的皮带磨得发白。爱达在那一刻清楚地知道，这就是她。和她很久以前认识的是同一个霍珀。
她在心里轻轻叹了一口气。不是失望的叹气，是一种“到了”的叹气。一个人等了二十一年的事到了，这瞬间不是激动，是一种安静的承认。
"霍珀？"
"嗯。"
"请坐。"

霍珀坐下的动作和她在 Noesis 会议室坐下的动作没有区别。她坐在了对面的那把扶手椅上，把公文包放在脚边，没有挑位置，没有犹豫，没有铺垫。她坐下来的时候后背靠到了椅背上，但只靠了一半，左手放在膝盖上，右手放在扶手上；她的姿态是一个习惯了被看着的人，她在董事会上、在公司 all-hands 上、在客户面前，一辈子都是这样坐的。
她坐下之后没有立刻看爱达，而是看着茶几上的一个空的玻璃杯，杯底还剩一点点茶色。爱达的笔记本放在旁边，封面是深蓝色的硬皮，看起来用了很多年。
爱达说，"我是林爱达。"
霍珀抬起头看着爱达，她眼睛里有那种长时间没睡的人的红，但她的眼神是定的。她可能很久没合眼，但她不是在游离，她是在场的。
她说，"对不起。"
爱达说，"为什么道歉？"
霍珀说，"我没准备好。"
爱达说，"准备什么？"
霍珀停了一下，她的视线从爱达的脸转到窗外，又转回来。
"我在路上一直在想我能跟你说什么。我没想出来。"
"你不需要说什么。"
霍珀看着她。霍珀的脸上闪过一瞬。是被一个完全没料到的回答打中的那种东西。她预设过这次见面的开头会怎么走、自己坐下来之后这个咨询师会问什么问题，她预设过自己怎么回答，甚至预设过自己什么时候可以提前走、用什么理由——从公寓开到 Palo Alto 的路上一直在想这些；她没有预设过对方说"你不需要说什么"。她的手在膝盖上动了一下，不是什么大的动作，是手指头无意识地在膝盖上的西装裤布料上按了一下。
爱达接着说，"你可以不说什么。我们就坐着。这五十分钟你想做什么都行。"
霍珀想了一下，"你不需要我说话。"
"不需要。"
"那你为什么——"她停住了。她意识到自己在问"那你为什么在这里"。这种问题已经把对方放在了需要解释自己存在的位置上，这是她在公司里跟一个她不打算尊重的副总裁说话的方式，不是她跟一个刚见面的女人在咨询室里应该用的方式。
"对不起。"
爱达笑了一下，她的眼睛弯成两道月牙，脸颊上起一点点褶，嘴张开露出一点牙。这个笑跟她坐在这把椅子上、跟她身上这件淡黄针织衫、跟她的乱头发、跟她整个人的气质完全合在一起，是一个没有专业感的笑，是一个邻居家小孩最爱的小姨那样的笑。"不用道歉。Helion 付我钱。不是你。"

沉默中，霍珀看着爱达，爱达看着霍珀，却不是对视。
爱达看人的方式，霍珀这一辈子没怎么遇到过，她不躲。普通人和你的眼神接触超过三秒就会飘掉，会去看你的肩膀或身后的墙，因为对视超过三秒就会变成评估或挑战或调情，没有第四种可能。
但霍珀在爱达这里看到了第四种可能。她的眼神里没有评估、没有挑战、没有调情、没有期待、没有探究、没有任何让你必须回应的东西，她只是看着你，像一个人看着窗外的雨——你不需要为雨做什么，你也不能为雨做什么，你只能让雨在那里。
霍珀经历过的看人的眼神大部分是评估的。她父亲一辈子卖保险，看人是评估能不能成单；Aaron Park 看她是评估能不能搞定她；她自己看人也是评估——这个工程师能不能做、这个经理能不能信。但爱达不是。
霍珀不太知道这种眼神是什么。
她坐了几秒，"你真的不用我说话。"
"真的。"
霍珀靠回椅背，她靠到椅背的全部，这是她进屋之后第一次让自己的身体真的接触到那把椅子。她闭了一下眼睛又睁开，"我接了一个案子。"
爱达依然看着她。
"周一晚上回家。我打开了我自己的——我有一个网站。叫 ping.hp。"
"上面有一个收件箱。匿名的。任何人可以发一段话，描述他们的 bug。我每周日下午看。"
"我周一晚上看了。里面有一条——"

霍珀开始讲那条投稿，她没说太多细节，只说一个工程师 push 了一段她不该 push 的代码，删了一个用户两年的医疗数据，老板让她签字承认是用户自己删的。
她讲她意识到那个工程师是 H1B。她讲她拒绝过 Aaron 但没付任何代价。她讲她记起 2017 年自己也曾听 HR 说过关于 H1B 的话。爱达一直听着。
讲到这里霍珀停了一下，说，"然后我做了一件事。"
"我申请了那家公司的一份 SRE contract 工作。"
"我去面试了。我应聘成功了。我拿到了内部 read access。"
"我读了他们的事故报告。报告说是那个工程师的错，我读了她的代码。她的代码确实有 bug，但我看到 reviewer 是另一个人，一个 staff engineer。我翻他的 commit history。"霍珀把整个事情的来龙去脉和她做了什么慢慢地说给爱达听。

爱达听完后，说："你让 Calix 内部自己问出真相。她不会知道是你做的。"
"她不会知道。我也不告诉她。"
"嗯。"
"我做了我能做的。我不知道结果。她可能下周仍然要签什么，也可能不签。我不知道。"霍珀的声音变了一点，"我从来没有过——"
"——我从来没有过一个 bug 我修不了的感觉。"
"二十多年以来，我每个 bug 都修。这个我修不了。我只能让它的形状改变一点。“
"我以为我能拒绝改报告是因为我有信念。今天我意识到——可能只是因为我有几百万存款。"
"那个工程师如果也有几百万存款、如果不是H1B，她也不会签那个用户误删数据的声明。"

爱达没说话。
霍珀的手机震动，是 Mei。

> 他们无限期推迟了会议。Reza 一小时前把 Alex 叫到了办公室，现在Alex还没出来。我不知道发生了什么，但今天没人让我签任何文件。
> 是你做了什么吗？

霍珀没有回复。她把手机翻过来扣在膝盖上，抬头看爱达。
爱达说，"嗯？"
霍珀说，"没事。"她笑了一下，一个非常小的的笑，"可能那个工程师今天不签了。"
霍珀靠回椅背。她说："我累了。这几天没怎么睡觉。但不是因为我失眠。是因为我没办法躺下。"
爱达说："嗯。"
霍珀说："我不知道我现在能做什么。"
爱达说，"你坐着。"
"就坐着？"
爱达说："就坐着。我也坐着。想说话就说话，不想说就不说，这五十分钟是你的。"
霍珀闭上了眼睛。
她坐着。


外面雨变小了。
霍珀拿起公文包，走到门口，回头。
"林医生。"
"嗯。"
"下周三？"
"下周三下午四点。"
"好。"
她出去。门轻轻合上。

【第十二场 / 周三晚上九点 / 霍珀家】
她拿起茶几上的书，翻到上周的书签，看了几行就把书合上，放在胸口，闭上了眼睛。
镜头慢慢拉开。
外面公路的车流声。
霍珀的呼吸平缓。
她睡着了。

镜头留在她睡着的脸上。
四十一岁，瘦削，脸上有几条疲惫的线。
她睡着的时候不像她平常的样子。
她睡着的时候看起来很年轻。
像一个十六岁的、没去 NOI 的、刚从北京西站坐火车回县城的人。

镜头停留。
黑屏。
