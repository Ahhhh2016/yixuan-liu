CS 释义：两个或多个进程同时访问共享资源，导致系统行为不可预测。最经典的形态是：A 和 B 几乎同时读写同一个变量，结果取决于谁先到，但"谁先到"事前无法被程序本身决定。

【第一场 / Crestwood 医疗中心 ICU / 凌晨三点十七分 / 单人病房】

监护仪屏幕。绿色的心率曲线刚才还匀地走着。

一下子炸开。

报警声一秒之后才追上来，刺，连续，停不下。Mr. Henry Liang，六十八岁，心脏支架术后第三天，眼睛闭着，脸是灰的，嘴角有一点白沫。心率监测从 78 跳到 142 又跳到 168，曲线像被人随手撕的纸边。

Marisol 从走廊冲进来。

她是夜班资深护士，三十二岁，单亲妈妈，UCSF 护士专业毕业，在 Crestwood 干了七年。她的鞋底是软的，跑起来不响。她到床边的动作比谁都快，那种快不是慌，是七年的肌肉记忆。她按 Code Blue，左手已经扣到 Henry 的颈动脉上。

"Code Blue, room 412. Code Blue, room 412."

走廊上脚步声涌过来。Crash cart 被推进门。一名住院医师跑进来，气喘。Marisol 已经把 Henry 的氧气面罩重新扣紧，左手按在他胸口数节奏。

她头不抬，"Amiodarone 八小时前给的。"

住院医师，"剂量？"

"Standard。两百毫克。"

"什么时候停的？"

Marisol 抬头看他，她的脸上有一秒钟非常具体的茫然，"没停。"

住院医师，"Dr. Ko 昨天下午写了 discontinue。"

Marisol，"我的 paper printout 上写的是 discontinue。但系统里是 active。"

她没解释更多。她回去按胸。

镜头退出病房，停在走廊上。报警声慢慢被各种声音吞掉。Code Blue 的脚步从急到缓，从缓到散。凌晨五点，Henry 被推进 ICU。他活着，但接下来三天观众都看不到他。

【第二场 / Crestwood HR 办公室 / 两周后 / 周五下午】

一个白色的办公室，没有窗。荧光灯。墙上挂着一张医院 logo 的画，颜色是淡淡的蓝绿。

Marisol 坐在桌子一边。她今天没穿护士服，穿一件浅灰色的针织衫和深色长裤，头发拢在脑后。她坐得很直，那种直是七年 ICU 站出来的，她自己都不知道她在坐直。她的手在膝盖上，没动过。

桌子对面是 HR Director Jeanette Park，五十岁出头，白人，灰色西装，疲惫但 professional。她戴着一副金丝边眼镜，眼镜后面的眼睛是温和的。她不是来害 Marisol 的，但她也救不了她。

Jeanette 翻一张打印纸，"Marisol，根据 Heliograph 的 audit log，一月十四号晚上九点三十四分你在系统里查看了 Mr. Liang 的医嘱，你看到了 Amiodarone 是 active 的。"

"Paper printout 上写了 discontinue。"

"系统是 source of truth。你被训练过的，'when system and paper conflict, system wins'。你违反了 protocol。"

Marisol，"我没有违反 protocol。我按了 protocol。Protocol 说 system over paper。系统说 active。我 administer 了。"

Jeanette 轻声，"Marisol。Protocol 在 conflict 时 system over paper。但 protocol 同样要求你在 conflict 时联系 attending。你没联系 Dr. Ko。"

"Dr. Ko 九点三十四分已经下班了。"

"我们的 record 显示她接到了你的电话，晚上九点四十一分。她说她不知道这件事。她说她没有 discontinue Amiodarone。"

Marisol 沉默。

她想——九点四十一是事后吗。她不记得了。她记得是事前。她记得她当时拿着手机站在配药间门口，纸面 discontinue，系统 active，她要打电话给 Dr. Ko 问清楚。她记得 Dr. Ko 没接。她记得她在手机上看着时间，等了一分钟，决定按系统执行。她记得她进病房，把 Amiodarone 推进 IV。

但她也记得 Henry 已经开始反应。她记得她回到护士站给 Dr. Ko 再打一次。她记得 Dr. Ko 这一次接了。

她不知道哪一个是真的。她只知道她做了她以为正确的事。

"你被停职。Pending 调查。这是医院的决定。你的工会代表已经通知你了。"

Marisol 站起来。她没说话。她走出 HR 办公室。

她走过走廊，从 ICU 楼层的电梯出来，走到一楼大厅。她在医院大门口停下，坐在长椅上。门是自动门，每隔一会儿打开一次，外面是十二月湾区的天气，有点冷，有云。

她不哭。

她拿出手机给她女儿发短信。

> mija. they let me go for now. don't worry.

镜头停在她的脸上。

黑屏。

片名出现。

UNDEFINED BEHAVIOR / 未定义行为

Episode Two: 竞态条件 / Race Condition


**第九场 · 二〇〇三年八月十二号 · 北京北航三楼 305 机房**

那一天热得不像话。下午两点的太阳直直地砸在水泥地上，知了叫得让人耳朵痒。爱达从北航的食堂走回机房楼，路上鞋底踩到柏油路上的沥青，粘了一下又松开。

机房在三楼。

她先从一楼的洗手间出来——洗手间镜子上面那盏白炽灯坏了，闪。她在镜子前面站了几秒，看自己。

她那天穿了一件白色的短袖 polo，下摆塞在牛仔短裤里——她妈让她塞的，她妈说"不塞看着邋遢"。她头发是中长的，扎成一个有点歪的马尾，发圈是粉色的。她没化妆，她妈不让，她自己也不会。她的手腕上戴着她爸去年从香山买的那种红绳。她十六岁，她一米五八。

她从镜子里看到她自己。

她对镜子里的自己说，"今天调出来。"

她说出声了。她吓了自己一跳，脸红了一下，赶紧出去。

---

机房楼三楼。

走廊的瓷砖是那种八十年代的米白色，缝里黑了一道一道。空气里有粉笔灰、电脑发热的塑料味、和不知道哪儿来的一点点豆浆味。窗户开着，窗外杨树的影子是动的。

爱达走到机房 305 门口。

她从门口的玻璃往里看——二十台电脑，坐了大概十六个人，全是男生。

她的视线一下子停在第二排靠窗的那个位置。

那里坐了一个人。

不是男生。

是一个女生。

爱达的心跳——

她把这件事记得很清楚——她的心跳变快了，不是吓的，是另一种，是那种你看到一个东西你早就在等的那种。

那个女生背对着门，爱达只看得到她的背；但爱达**知道**是谁。不是因为她的脸——爱达还看不到脸——是因为那个女生的肩膀很瘦，比一般女生瘦很多，肩膀宽，但瘦；她穿一件大一号的黑色 T 恤，T 恤的下摆盖到大腿上，袖子盖过手腕；她的脖子从 T 恤的领口里出来——长，很白；她的头发是短的，非常非常短，比男生的头发还短一点点，到耳朵以上。

爱达入营第一天就把名单背下来了。

她在入营第一天就注意到一个名字——河北省 2001 届集训队、因故未参赛——这一行字写得很轻，但爱达把它读了三遍。

她那天问她的室友——北京二中的一个女生——你知道这个霍珀是谁吗？

室友说，你问她干什么。

爱达说，没什么。

室友说，传说中的人物。我听我们老师讲过。她那年去 IOI 选拔，她是国家集训队前五，最后没去。

爱达说，为什么没去。

室友说，不知道。我们老师也不知道。她说她家里的事。也有人说不是。反正没去。

爱达说，那她现在干什么。

室友说，大学。北大。

爱达点头。她那天晚上睡不着。她想象一个十六岁的女孩，前五名，最后没去——爱达想象她自己，她想象自己如果是她——爱达想到这里就停下来——爱达自己连河北省队都进不去，她是北京八中的，她在北京排第二十六名，她这次能来夏令营是因为前面的人有几个临时阑尾炎住院。她在全国——她没数过。她不敢数。

爱达的室友过两天又跟她说，她每年回来当助教。她给营里讲课。

爱达说，她讲什么。

室友说，讲算法。她讲得特别快。我去年来的时候听过。我听不懂。

爱达说，我能听懂吗。

室友说，你能。你比我强。

爱达没说话。

爱达那天晚上趴在床上想——

我能听懂吗。

---

她在机房门口站了大概五秒。

她推门进去。

机房里很安静。所有人都在敲键盘。空调开得很冷——那种老式的工业空调，从天花板上的一个铁皮盒子里一直吹下来。爱达进门那一秒打了个寒颤。

她不敢看那个第二排靠窗的位置。

她回自己的座位——第四排第三个，靠走道。她坐下。

她偷偷往第二排看了一眼。那个女生还是背对着她，那个女生在打字，打得很快；爱达看不到她的屏幕，但爱达能看到她的肩膀——肩膀几乎不动，一个打字快的人肩膀不动；爱达自己打字的时候肩膀会动，她的语文老师说过她——你打字怎么像在搬砖。

爱达把脸转回自己的屏幕。

她调那道题。

那是一道区间 DP 加决策单调性的题——给一个长度为 5000 的序列，把它划分成 100 段，每段有一个代价函数，最小化总代价；朴素 DP 是 O(n²k) 会超时，要用决策单调性的分治优化降到 O(nk log n)。这是 NOI 集训队级别的题，北京前几名会写，她这种排名要使尽全力——她从昨天下午调到现在。

她的代码：

```cpp
void solve(int l, int r, int optl, int optr) {
    if (l > r) return;
    int mid = (l + r) >> 1;
    int opt = optl;
    for (int j = optl; j <= min(mid, optr); j++) {
        long long val = dp[i-1][j] + cost(j+1, mid);
        if (val < dp[i][mid]) {
            dp[i][mid] = val;
            opt = j;
        }
    }
    solve(l, mid - 1, optl, opt - 1);
    solve(mid + 1, r, opt, optr);
}
```

她跑前三个样例——对。

第四个——错。

不是错得离谱，是错那么一点点——大约 5%。

她查 cost 函数，对；她查 dp 初始化，对；她查 i 和 j 的循环边界，对；她在草稿纸上手算第四个样例的前几个状态，对；她跑她的程序到第四个样例，错。

她已经查了三个小时。

她不知道哪里错。

她没去看 solve 函数的递归调用——因为她写的时候是抄板的，她抄的是 OI Wiki 上贴的板子，她确定那两行不会错。

机房里其他人陆续做完，陆续走。机房里只剩她和——

她不敢回头。

她在屏幕上看不到那个女生还在不在，但她能听——空调声里有一种细的、规律的、键盘的声音，啪嗒啪嗒，那个键盘声没有停过；所以那个女生还在。

爱达低头看自己的代码。

她突然意识到一件事——她调了三个小时，但她最后这十分钟一直在听那个键盘声。

她脸又红了一下。

她对着屏幕跟自己说，专心。

---

下午五点二十五。

那个键盘声停了。

爱达听见椅子拖在地上的声音。

她的肩膀绷紧。

她不敢回头。

她听见**脚步**——那个脚步不往机房门口走，那个脚步往她这边走。

爱达的手放在键盘上不敢动。她看着屏幕，她在屏幕上看不到，她只看到自己的代码——

脚步停了。

停在她身后。

爱达的耳朵——爱达听见自己心跳。她听见自己心跳是因为机房里太安静了。她想——那个人会不会听见。

那个人没有立刻说话。

那个人——

那个人**弯下来了**。

爱达知道她弯下来了，因为爱达的右肩边突然多了一片影子——空调灯的光被挡了一点。

那一刻爱达——爱达想到一个非常奇怪的事：那个人的 T 恤的领口，离她的右肩，大概只有十厘米。

爱达**没回头**。

爱达的身体不敢动。

那个人盯着爱达的屏幕，三秒。

爱达听见她的呼吸，一次，轻。

她的手——伸出来——食指——

那只手——爱达后来回想这件事的时候，最先回想起来的是那只手。那只手是一只很瘦的手，指节明显，手背的皮肤很白，指甲剪得非常短，很干净，手指长。那只手没有戴任何东西，没有戒指，没有手链，手腕上没有表。

那只手伸过爱达的右肩——伸到屏幕前——食指点在那一行——

```
solve(l, mid - 1, optl, opt - 1);
```

她的食指没碰屏幕，她的食指**离屏幕**大概一厘米，但是非常稳，一动不动。

她说话了。

"这里。"

"opt 减一不对。"

"你想想为什么。"

她的食指收回去。

那个人站直，转身。

爱达没回头。爱达只听到那个声音。那个声音——平，低一点点，不是温柔，不是批评，不是讲解的声音，是一种像她在说今天是 8 月 12 号那种声音。

那个人走到机房后面——拿了一份纸——走回来——经过爱达——她的左眼角的余光，只看到一条牛仔裤的裤腿，一双白色的、有点旧的运动鞋，袜子是男生那种黑色的中筒袜，袜子上沿露出一点点小腿——非常瘦，皮肤白——

机房门**开**——机房门**关**。

爱达——爱达坐着。她不动。

她听机房里——只有空调声。

她的手——还在键盘上。

爱达盯着那一行。

opt 减一为什么不对。

她想——决策单调性的递归——左子区间的决策范围——

她**愣了一秒**——

她想到了。

她在心里听到自己说——决策单调性是非严格的。opt 可以在 mid 出现，也可以在 mid 左边某个位置出现。如果决策不严格，opt 自己也可能是左子区间的最优决策；如果我减一，我把这个可能性砍掉了。

她——

她在屏幕前坐了两秒没动。

她改了那一行。opt - 1 改成 opt。

她按编译。她按运行。

第四个——对。

第五个——对。

第六个——对。

正确。正确。正确。

爱达——

爱达盯着屏幕。

她意识到——

那个学姐**不是给我讲解**。

那个学姐**留了一个问题给我**。

那个学姐——

那个学姐**相信我能想出来**。

爱达的手放在键盘上**抖**。

她不知道为什么抖。

她抖着抖着——她趴在键盘上**笑了**。

她不敢笑出声——机房里没人但她不敢——但她身体在笑，她肩膀在颤，她趴在键盘上——她的额头碰到键盘——她笑——

笑了大概十秒。

她抬头。

她的眼睛湿了。她不知道为什么湿。她抹了一下。

她抬头看机房门口。门关着。

那个人已经走了。

爱达坐了五分钟。她什么都没做。她就坐着。

她屏幕上是那一行：

```
solve(l, mid - 1, optl, opt);
```

她看着这一行。

她想——

这一行是她改的。

不是。是她让我改的。

——是她让我自己改的。

她没动我的键盘。她离我十厘米。她食指离我屏幕一厘米。她说三句话。她走了。

这一行是我改的。

爱达的手放在键盘上。她的手指头**还能感觉到刚才那一秒——按下 opt 的那一秒**。

她的右肩——

爱达**抬起左手**，抹了一下右肩——好像那里还有什么——

什么都没有。

爱达保存代码。关机器。她拎起书包出机房。

走廊里的光是夏天傍晚的光——黄的，斜的，空气里有食堂的味道，是晚饭的味道。

她下楼。

她路过一楼的公告栏。

公告栏上贴着夏令营的名单。

她停。

她看名单。

她看到那个名字。

她已经知道是哪一个，但是她还是要看。

她看着那个名字看了三十秒。

她**用食指**——刚才那只手食指的位置，大概——在那个名字上面**轻轻点了一下**。她不敢碰名单——她碰了纸。她意识到自己在干什么，她脸又红了一下，她把手缩回去。

她快步走出机房楼。

---

宿舍楼。

爱达上楼。她和三个北京来的女生一起住，其中两个不在，去吃饭了，剩下一个是她室友——北京二中那个。

爱达进门。

室友抬头。"你脸怎么红的。"

"没。"

"中暑了？要不要喝水？"

"没事。我洗澡。"

她进卫生间，关门。她对着镜子站了大概三秒。

她笑了。

不是大笑，是那种你自己看着镜子里的自己一个人笑——那种笑非常奇怪——她脸还红，她眼睛亮，她头发因为出汗有几根贴在额头上——

她跟镜子里的自己说，"她跟我说话了。"

她说出声了，她吓了自己一跳，她又脸红了一下，她赶紧打开水，把脸埋在水里。

---

她洗完出来，躺上铺。

灯没关——她室友在桌前看一本书，是英语词汇书。

爱达躺着，她看天花板。天花板上有一道裂缝，从中间往窗户那边走。

爱达想——

我要成为这样的人。

她想——

我要成为一眼看穿 bug 的人。

她想——
