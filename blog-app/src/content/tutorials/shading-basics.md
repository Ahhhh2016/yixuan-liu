## 1. Lambert and Blinn-Phong

Implement both models under identical lighting and camera setup, then compare highlights and shadow transitions.

## 2. Normal Mapping

Apply tangent-space normal maps and verify TBN construction correctness. Incorrect basis vectors are usually the first source of artifacts.

## 3. Debug Views

Add albedo-only, normal-only, and roughness-only modes so every channel can be validated independently.

## 4. Exercise

Switch between shading models at runtime and document visual differences with screenshot pairs.
