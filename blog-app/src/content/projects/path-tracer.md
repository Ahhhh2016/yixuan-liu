## Motivation

This project started from one question: how far can a small personal renderer go while still being understandable and modifiable?

## What I built

- Monte Carlo path tracing with diffuse and glossy materials
- Direct and indirect lighting accumulation
- Scene setup with controlled camera framing and test shots

## Notes

I use this renderer as a lab notebook. Every optimization is measured against image quality, not only speed, because visual clarity is the final product.
